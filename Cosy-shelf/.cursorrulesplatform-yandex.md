# YANDEX GAMES REQUIREMENTS

## SDK
- SDK инициализируется только через `YandexAdapter`.
- `LoadingAPI.ready()` — когда игра реально играбельна.
- `GameplayAPI.start/stop` — соответствуют геймплею.

## Ads
- Fullscreen: пауза игры и звука, resume в `onClose`.
- Rewarded: только по действию пользователя, награда гарантирована.
- Никаких кастомных рекламных блоков.
- Частота interstitial — управляется remote config, дефолт не чаще
  1 раза в 3 минуты и не в первой сессии.

## Packaging
- `index.html` в корне ZIP.
- Имена файлов — латиница, без пробелов.
- Распакованный размер < 100 MB.
- Пути к ассетам — относительные.

## Saves
- Прогресс сохраняется сразу после действия игрока.
- Работает гостевой режим, прогресс не теряется при обновлении.
