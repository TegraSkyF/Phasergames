# Phasergames — Змейка

Простая 2D-змейка на **Phaser 3** + Vite.

## Управление

- **Стрелки** или **WASD** — движение
- **Кнопки ▲ ◀ ▼ ▶** на экране — то же самое
- **Пробел** / клик — старт и рестарт
- **Esc** — в меню после проигрыша

## Правила

- Съешь яблоко — вырастешь и получишь очко
- Скорость чуть растёт с каждым яблоком
- Столкновение со стеной или собой — конец игры

## Запуск

```bash
npm install
npm run dev
```

Открой http://127.0.0.1:5173/
