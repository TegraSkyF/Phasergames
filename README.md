# Phasergames

Минимальный проект на **Phaser 3** + Vite для проверки подключения движка.

## Статус подключения

- Пакет: `phaser@3.90.0`
- Dev-сервер: `npm run dev` → http://127.0.0.1:5173/
- При успехе на странице: `Phaser 3.90.0 подключён. Сцена запущена.`

## Команды

```bash
npm install
npm run dev
npm run build
```
